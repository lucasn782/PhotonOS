# Intel e1000 PCI Network Driver

This document details the configuration registers, physical DMA ring buffers, and Bus Mastering settings of the Intel e1000 network interface card driver in PhotonOS.

---

## 1. Device Profile and MMIO BAR Mappings

The e1000 driver target is the **Intel 82540EM Gigabit Ethernet Controller**, virtualized by QEMU:
- **Vendor ID**: `0x8086`
- **Device ID**: `0x100E`

During PCI scanning, the kernel reads **BAR0** to retrieve the base address of the card's register space, mapping it with caching disabled to prevent memory accesses from being reordered or cached.

---

## 2. Bus Mastering Configuration

To enable Direct Memory Access (DMA), the driver enables **PCI Bus Mastering**:
- Modifies the PCI Command Register (offset `0x04`) in the device's configuration space.
- Enables bit `2` (`PCI_COMMAND_BUS_MASTER`), which allows the card to directly read and write system RAM without involving the CPU.

---

## 3. Physical DMA Rings Setup

The driver allocates physical page frames via the PMM (`pmm_alloc`) to construct the transmit (TX) and receive (RX) rings:

- **RX Ring**: Contains `E1000_NUM_RX_DESC` (typically 32) descriptors. Each descriptor points to a physical frame allocated for receiving packets.
- **TX Ring**: Contains `E1000_NUM_TX_DESC` descriptors.

### Registers Mapping:
- **`E1000_RDBAL` / `E1000_RDBAH`**: Tells the card the physical base address of the RX ring.
- **`E1000_RDLEN`**: Length of the RX ring in bytes.
- **`E1000_RDH` / `E1000_RDT`**: Head and Tail index pointers tracked by the card.
- **`E1000_RCTL`**: Receive Control register, configured to enable the receiver, strip Ethernet CRC (`E1000_RCTL_SECRC`), and set buffer sizes.

---

## 4. Packet Transmit and Receive Flows

- **Transmission (`e1000_send_packet`)**:
  1. Writes the packet data to a pre-allocated DMA buffer.
  2. Sets the descriptor length and physical address (`vmm_virt_to_phys` of the buffer).
  3. Increments the `E1000_TDT` tail pointer. The card's DMA automatically reads the memory and sends the packet.
- **Reception (`e1000_recv_packet`)**:
  1. Polls the current descriptor index in the RX ring.
  2. If the status bit `E1000_RXD_STAT_DD` (Descriptor Done) is set, the card has filled the buffer via DMA.
  3. Copies the packet, clears the status bit, and advances the tail pointer `E1000_RDT` to release the descriptor back to the card.
